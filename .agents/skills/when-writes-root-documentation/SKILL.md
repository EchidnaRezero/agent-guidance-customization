# When Writes Root Documentation

## Rules

- If you review a root-level document, read `C:\Projects\skills\AGENTS.md` and apply the `Root Documentation` rules.
- If the document explains itself, narrates changes, repeats content, or restates what structure, diagrams, or flowcharts already show, delete or rewrite that text.
- If the document includes update history or before/after change text, rewrite it so that only the final results remains.
- If duplicate or overlapping content appears within a document or across documents, ask the user before merging, consolidating, or absorbing it.
