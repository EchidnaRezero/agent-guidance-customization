# when-writes-and-check-md_doc

## 작성 기준

### 기본 내용

- 별도 세부 지침이나 사용자의 직접 지시가 없다면, 문서에는 기본적으로 다음 내용만 씁니다.
  - 목적: 무엇으로 무엇을 하기 위한 것인지 한 줄 설명. 제목만으로도 충분하면 생략합니다.
  - 구조
  - 동작 순서
  - 사용법

### 명시적 요청 없이는 쓰지 말 것

- 사용자가 직접 요청하지 않았다면 다음은 쓰지 않습니다.
  - 당위
  - 해설
  - 문서에서 다루지 않는 것, 하지 않는것. 단, 특정 행동이나 명령어, 구체적인 행위를 금지하는 것이 문서의 목적이라면 작성할 수 있습니다.
  - 중복된 내용, 또는 이미 다른 곳에서 했던 말과 비슷한 내용
  - 구조, 다이어그램, 플로우차트를 보면 바로 아는 내용
  - 변경 설명
  - 내용 자체에 꼭 필요한 경우가 아니면 문서 자체를 설명하는 메타 문구
  - 문서 변경/삭제로 인해 현재는 문서에서 없어진 내용에 대한 설명
- 기본/지침에서 정한 내용 외에 문서에 작성할 필요가 있는 내용이라면, 먼저 사용자에게 확인합니다.

### 로컬 경로와 개인정보

- 사용자의 확인 없이 프로젝트 루트 상위 경로나 외부 로컬 경로를 쓰지 않습니다.
- 사용자의 확인 없이 이름, 계정 정보, 개인 정보처럼 보이는 내용을 쓰지 않습니다.

### 표현 방식

- 구조와 동작을 다루는 문서는 적절한 시각화 도구로 전체상을 먼저 제시합니다. 단, 항목이 많다면 적절하게 분할합니다.
- 줄글이 5줄 이상으로 길어지면 항목별로 분할합니다.

## 검토 기준

- 문서가 위 작성 기준에 맞게 쓰였는지 확인합니다.
- 문서 작성 및 변경 후에는 문서 전체를 읽어서 중복되는 내용, 비슷한 내용이 있는지 검토하고, 문서 안이나 문서 사이에 겹치는 내용을 합치거나 정리하거나 흡수하기 전에는 사용자에게 확인합니다.
