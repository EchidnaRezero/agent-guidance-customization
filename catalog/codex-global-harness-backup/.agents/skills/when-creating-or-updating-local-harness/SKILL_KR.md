# When Creating Or Updating Local Harness

## 주의

- 이 스킬 자체는 홈의 `.codex`에 저장되는 전역 스킬입니다.
- 하지만 작용 대상은 개별 프로젝트의 로컬 하네스입니다.
- 적용 파일은 한 프로젝트의 `AGENTS.md`, `README.md`, 로컬 스킬입니다.

## 규칙

- 먼저 기존 `AGENTS.md`, `README.md`, 로컬 스킬을 확인합니다.
- 새 guidance 파일을 만들기 전에 기존 guidance를 먼저 수정합니다.
- `AGENTS.md`는 행동 규칙에 집중하게 유지합니다.
- `README.md`는 사람을 위한 구조와 사용법에 집중하게 유지합니다.
- 문서는 짧고, 최종형만 남기고, 중복이 없게 유지합니다.
- 로컬 스킬은 그 워크플로가 반복되어 스킬로 분리할 가치가 있을 때만 추가합니다.
