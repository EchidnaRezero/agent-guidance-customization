# PowerShell 명령 안전성 점검

## 범위

- 계획한 명령이 현재 격리 경계 밖의 시스템 수준 자원을 변경할 수 있을 때만 발동합니다.
- 영향이 현재 프로젝트 폴더, 작업 공간, 샌드박스, 컨테이너 또는 이와 유사한 격리 환경 안에 한정되면 발동하지 않습니다.

## 승인

1. 외부 경로, 서비스, 설치된 소프트웨어, 계정, 시스템 구성, 보안 제어 또는 네트워크 등 명령이 영향을 줄 수 있는 정확한 시스템 범위를 확인합니다.
2. 그 범위와 구체적인 위험을 사용자에게 설명합니다.
3. 해당 범위로 명령을 실행해도 되는지 명시적으로 승인해 달라고 요청합니다.
4. 사용자가 명시적으로 승인하기 전에는 명령을 실행하지 않습니다.
